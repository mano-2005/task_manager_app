# 📱 Task Manager App (Flutter)

A simple **Task Management App** built using Flutter as part of an internship project.  
The app allows users to add, delete, and mark tasks as complete, with data persistence using **SharedPreferences** and optional **Firebase Firestore integration** for cloud sync.

---

# 🚀 Features

- ➕ Add new tasks
- 🗑️ Delete tasks
- ☑️ Mark tasks as complete/incomplete
- 💾 Local storage using SharedPreferences
- ☁️ Firebase Firestore integration (real-time sync)
- ⏳ Splash screen (bonus feature)
- 🎨 Simple and clean UI with icons
- 🔄 Real-time updates using StreamBuilder

---

# 🧱 Tech Stack

- Flutter
- Dart
- SharedPreferences
- Firebase Core
- Cloud Firestore
